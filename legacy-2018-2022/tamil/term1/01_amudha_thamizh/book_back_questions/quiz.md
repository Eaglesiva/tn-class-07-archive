# 7-ஆம் வகுப்பு தமிழ் — 1.1 எங்கள் தமிழ் — Quiz

## STEP 2 — Original Textbook MCQ

1. ‘நெறி’ என்னும் சொல்லின் பொருள் _________.
   - அ) வழி
- ஆ) குறிக்கோள்
- இ) கொள்கை
- ஈ) அறம்
   **விடை:** அ
   **விளக்கம்:** பாடல் சூழலில் ‘நெறி’ என்பது வழி அல்லது அறவழி என்ற பொருளில் வருகிறது.
   **Source:** [Book Back Guide](https://textbookpdf.in/tn-7th-tamil-guide-term-1-lesson-1-1/)

2. ‘குரலாகும்’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது _________.
   - அ) குரல் + யாகும்
- ஆ) குரல் + ஆகும்
- இ) குர + லாகும்
- ஈ) குர + ஆகும்
   **விடை:** ஆ
   **விளக்கம்:** ‘குரல்’ + ‘ஆகும்’ சேர்ந்து ‘குரலாகும்’ என அமைகிறது.
   **Source:** [Book Back Guide](https://textbookpdf.in/tn-7th-tamil-guide-term-1-lesson-1-1/)

3. ‘வான் + ஒலி’ என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் _________.
   - அ) வான்ஒலி
- ஆ) வானொலி
- இ) வாவொலி
- ஈ) வானெலி
   **விடை:** ஆ
   **விளக்கம்:** ‘வான் + ஒலி’ புணர்ந்து ‘வானொலி’ என அமைகிறது.
   **Source:** [Book Back Guide](https://textbookpdf.in/tn-7th-tamil-guide-term-1-lesson-1-1/)
