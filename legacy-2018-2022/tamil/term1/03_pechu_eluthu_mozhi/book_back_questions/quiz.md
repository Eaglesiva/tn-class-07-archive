# 7-ஆம் வகுப்பு தமிழ் — 1.3 பேச்சுமொழியும் எழுத்துமொழியும் — Quiz

## STEP 2 — Original Textbook MCQ

1. மொழியின் முதல் நிலை பேசுதல், _________ ஆகியனவாகும்.
   - அ) படித்தல்
- ஆ) கேட்டல்
- இ) எழுதுதல்
- ஈ) வரைதல்
   **விடை:** ஆ
   **விளக்கம்:** பாடம் பேசுதலும் கேட்டலும் மொழியின் முதல் நிலை எனக் குறிப்பிடுகிறது.
   **Source:** [Book Back Guide](https://textbookpdf.in/tn-7th-tamil-guide-term-1-lesson-1-3/)

2. ஒலியின் வரிவடிவம் _________ ஆகும்.
   - அ) பேச்சு
- ஆ) எழுத்து
- இ) குரல்
- ஈ) பாட்டு
   **விடை:** ஆ
   **விளக்கம்:** ஒலியை வரிவடிவில் பதிவு செய்வதே எழுத்து வடிவம்.
   **Source:** [Book Back Guide](https://textbookpdf.in/tn-7th-tamil-guide-term-1-lesson-1-3/)

3. தமிழின் கிளைமொழிகளுள் ஒன்று _________ .
   - அ) உருது
- ஆ) இந்தி
- இ) தெலுங்கு
- ஈ) ஆங்கிலம்
   **விடை:** இ
   **விளக்கம்:** தெலுங்கு தமிழிலிருந்து பிரிந்த திராவிடக் கிளைமொழிகளில் ஒன்றாகப் பாடத்தில் குறிப்பிடப்பட்டுள்ளது.
   **Source:** [Book Back Guide](https://textbookpdf.in/tn-7th-tamil-guide-term-1-lesson-1-3/)

4. பேச்சுமொழியை _________ வழக்கு என்றும் கூறுவர்.
   - அ) இலக்கிய
- ஆ) உலக
- இ) நூல்
- ஈ) மொழி
   **விடை:** ஆ
   **விளக்கம்:** பாடத்தில் பேச்சுமொழி உலக வழக்கு என்றும் எழுத்துமொழி இலக்கிய வழக்கு என்றும் விளக்கப்படுகிறது.
   **Source:** [Book Back Guide](https://textbookpdf.in/tn-7th-tamil-guide-term-1-lesson-1-3/)
