## ஒரு வேண்டுகோள் — சரியான விடையைத் தேர்ந்தெடுத்து எழுதுக

1. மயிலும் மானும் வனத்திற்கு ______ தருகின்றன.
   - (அ) களைப்பு
   - (ஆ) வனப்பு
   - (இ) மலைப்பு
   - (ஈ) உழைப்பு

2. மிளகாய் வற்றலின் ______ தும்மலை வரவழைக்கும்.
   - (அ) நெடி
   - (ஆ) காட்சி
   - (இ) மணம்
   - (ஈ) ஓசை

3. அன்னை தான் பெற்ற ______ சிரிப்பில் மகிழ்ச்சி அடைகிறார்.
   - (அ) தங்கையின்
   - (ஆ) தம்பியின்
   - (இ) மழலையின்
   - (ஈ) கணவனின்

4. ‘வனப்பில்லை’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது ______.
   - (அ) வனம் + இல்லை
   - (ஆ) வனப்பு + இல்லை
   - (இ) வனப்பு + யில்லை
   - (ஈ) வனப் + இல்லை

5. ‘வார்ப்பு + எனில்’ என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் ______.
   - (அ) வார்பெனில்
   - (ஆ) வார்ப்பினில்
   - (இ) வார்ப்பெனில்
   - (ஈ) வார்ப்பு எனில்

## கீரைப்பாத்தியும் குதிரையும் — சரியான விடையைத் தேர்ந்தெடுத்து எழுதுக

1. ‘ஏறப் பரியாகுமே’ என்னும் தொடரில் ‘பரி’ என்பதன் பொருள் ______.
   - (அ) யானை
   - (ஆ) குதிரை
   - (இ) மான்
   - (ஈ) மாடு

2. பொருந்தாத ஓசை உடைய சொல் ______.
   - (அ) பாய்கையால்
   - (ஆ) மேன்மையால்
   - (இ) திரும்புகையில்
   - (ஈ) அடிக்கையால்

3. ‘வண்கீரை’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது ______.
   - (அ) வண் + கீரை
   - (ஆ) வண்ணம் + கீரை
   - (இ) வளம் + கீரை
   - (ஈ) வண்மை + கீரை

4. ‘கட்டி + அடித்தல்’ என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் ______.
   - (அ) கட்டியிடித்தல்
   - (ஆ) கட்டியடித்தல்
   - (இ) கட்டி அடித்தல்
   - (ஈ) கட்டுஅடித்தல்

## பேசும் ஓவியங்கள் — சரியான விடையைத் தேர்ந்தெடுத்து எழுதுக

1. குகை ஓவியங்களில் வண்ணம் தீட்டப் பயன்பட்ட பொருள்களில் ஒன்று ______.
   - (அ) மண்துகள்
   - (ஆ) நீர் வண்ணம்
   - (இ) எண்ணெய் வண்ணம்
   - (ஈ) கரிக்கோல்

2. நகைச்சுவை உணர்வு வெளிப்படுமாறு வரையப்படும் ஓவியம் ______.
   - (அ) குகை ஓவியம்
   - (ஆ) சுவர் ஓவியம்
   - (இ) கண்ணாடி ஓவியம்
   - (ஈ) கேலிச்சித்திரம்

3. ‘கோட்டோவியம்’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது ______.
   - (அ) கோடு + ஓவியம்
   - (ஆ) கோட்டு + ஓவியம்
   - (இ) கோட் + டோவியம்
   - (ஈ) கோடி + ஓவியம்

4. ‘செப்பேடு’ என்னும் சொல்லைப் பிரித்து எழுதக் கிடைப்பது ______.
   - (அ) செப்பு + ஈடு
   - (ஆ) செப்பு + ஓடு
   - (இ) செப்பு + ஏடு
   - (ஈ) செப்பு + யேடு

5. ‘எழுத்து + ஆணி’ என்பதனைச் சேர்த்தெழுதக் கிடைக்கும் சொல் ______.
   - (அ) எழுத்துஆணி
   - (ஆ) எழுத்தாணி
   - (இ) எழுத்துதாணி
   - (ஈ) எழுதாணி

## திறந்த / குறு / சிறு வினாக்கள்

### ஒரு வேண்டுகோள்
1. தாய்மையின் ஓவியத்தில் நிறைந்திருக்க வேண்டியவை யாவை?
2. ஒரு கலை எப்பொழுது உயிர்ப்புடையதாக அமையும்?
3. சிற்பங்களும் ஓவியங்களும் எவ்வாறு அமைய வேண்டும் என்று கவிஞர் கூறுகிறார்?
4. நீங்கள் ஒரு கலைஞராக இருந்தால் எத்தகைய படைப்புகளை உருவாக்குவீர்கள்?

### கீரைப்பாத்தியும் குதிரையும்
1. கீரைப்பாத்தியும் குதிரையும் எக்காரணங்களால் ஒத்திருக்கின்றன?
2. நீங்கள் எவற்றைக் குதிரையோடு ஒப்பிடுவீர்கள்?

### பேசும் ஓவியங்கள்
1. ஓவியங்களின் வகைகள் யாவை?
2. குகை ஓவியங்களில் இருந்து நாம் அறியும் செய்திகள் யாவை?
3. தாள் ஓவியங்களை எவற்றைக் கொண்டு வரைவர்?
4. சுவர் ஓவியங்கள் காணப்படும் இடங்களைக் கூறுக.
5. செப்பேட்டு ஓவியங்களில் காணப்படும் காட்சிகள் யாவை?
6. கேலிச்சித்திரம் என்றால் என்ன?
7. ஓலைச்சுவடி ஓவியங்கள் குறித்து நீங்கள் அறிந்து கொண்டவற்றை எழுதுக.
8. தந்த ஓவியங்கள் கேரளாவில் அதிகம் காணப்படுவது ஏன்?
